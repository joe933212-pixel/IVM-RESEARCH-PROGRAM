# Working Hypothesis

Institutional execution contains semantic requirements that are not naturally represented as first-class objects by conventional application runtimes.

The IVM model treats an institutional transition as an explicit computational object associated with event identity, authority, rule version, pre-state, post-state, commitment and historical evidence.

The hypothesis is not that existing systems cannot implement these properties. The testable question is whether they provide them naturally as part of their execution model or require additional structures equivalent in substance to an institutional-transition abstraction.
