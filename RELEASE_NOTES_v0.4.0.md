# Release Notes — IVM Research Repository v0.4.0

This release adds the research-claims layer and the funder-facing research pathway while preserving the complete v0.3 repository contents.

New research documents include:

`docs/RESEARCH_CLAIMS_REGISTER.md`

`docs/RESEARCH_ROADMAP.md`

`proposals/FUNDER_RESEARCH_BRIEF.md`

`proposals/FUNDER_EVALUATION_GUIDE.md`

The README now provides a direct reviewer path from research evidence to funding rationale.

No historical experiment result has been replaced by a packaging-time rerun, and no incomplete literature analysis has been represented as complete.
